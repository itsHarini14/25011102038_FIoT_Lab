# CAT9 — STM32 UART Command Controlled LED

Tasks from the sheet:
- TASKA (9A) — Basic UART communication: transmit character; receive and echo.
- TASKB (9B) — String-based command interface: `LED ON`, `LED OFF`, `LED TOGGLE`.

Use the UART connected to the PC terminal. Configure baud rate/word length/stop bits in CubeMX and match the terminal.
